# 三到五分钟演示脚本

## 演示前准备

```bash
cd /Users/tanjiayu/Documents/Codex/2026-10-27/xia
PYTHONPYCACHEPREFIX=/tmp/signalwatch-pycache python3 app.py
```

打开 `http://127.0.0.1:8765`。

如果配置了模型，先确认页面显示 `AI + 规则 · 模型名`；如果没有模型，明确说明本次演示使用规则引擎。

## 演示流程

### 1. 说明问题边界

> 系统监测的是声明数据源范围内的公开热榜、新闻和授权接口，不把未覆盖来源解释为“全网无舆情”。

展示数据源健康状态和覆盖边界。

### 2. 输入监测对象

输入一个当前热榜可能命中的品牌或人物，点击“保存并扫描”。

### 3. 展示 Agent 轨迹

打开“Agent 轨迹”，展示：

- 查询计划
- 来源成功和失败
- 规则研判数量
- 模型调用状态
- 告警候选
- 运行耗时

### 4. 打开事件

展示：

- 事件摘要
- 风险等级
- 命中监测词
- 证据链和原文链接
- 首次发现时间
- 人工状态
- AI 摘要和核查问题（如已配置模型）

### 5. 导出报告

点击“导出 Markdown 报告”，展示报告包含证据、覆盖说明和责任边界。

### 6. 展示告警送达

如果已配置 Webhook 或邮件，展示对应告警正文。不要在现场暴露真实密钥。

### 7. 展示评测基线

打开 `outputs/evaluation-report.md`，说明：

> 这是合成回归集，不是真实业务准确率。规则版告警精确率为 100%、召回率为 80%，未通过案例集中在需要语义理解的场景。

## 现场不要说的话

- “全网监测”
- “已经达到生产级”
- “AI 自动处理危机”
- “准确率 100%”
- “自研大模型”
